# Chatgpt-codelab

A minimal ChatGPT UI setup: a single line of interface code, a prompt, and instructions for ChatGPT.

## What's in here

| File | Purpose |
|------|---------|
| `ui.[html/js/txt]` | The one-line UI code for the chat interface |
| `prompt.[txt/md]` | The prompt used with ChatGPT |
| `instructions.md` | instructions for chat gpt to follow and what to read in order |
| `README.md` | This file |

## Usage

chat gpt comes to this and reads the prompt(s), uses the code, and leaves. 

## Notes

- This is a small, single-purpose setup—no build step, no dependencies.
- The UI snippet is meant to be dropped in as-is.
